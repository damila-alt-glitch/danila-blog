# По ту сторону экрана — учебный блог Данилы

Статический личный блог на HTML, CSS и JavaScript по материалам предоставленных лекций. Файлы страниц открываются напрямую; установка зависимостей и сборка не требуются.

## Страницы

- `index.html` — главная, знакомство, четыре карточки записей, фильтр и карусель из четырёх фотографий.
- `interests.html` — четыре увлечения и встроенная игра «Динозаврик и кактус» по Л15.
- `recommendations.html` — шесть аниме, фильмов и сериалов и восемь книжных рекомендаций.
- `places.html` — «Моя мастерская»: тематическая замена страницы мест, разрешённая заданием.
- `favorite.html` — любимый фиолетовый цвет и палитра блога.
- `404.html` — страница ошибки; не входит в пять основных страниц.

На всех пяти основных страницах одинаковое меню, общий `css/style.css` и мобильная версия. Все локальные ресурсы подключены относительными путями. Фотографии, постеры и книжные обложки подключаются обычным тегом `img`, а персонажи игры — через CSS `background-image`. Изображения расположены в `img/real/`; источники и лицензии указаны в `CREDITS.md` и на странице `credits.html`. Оформление использует прямые края и контрастные рамки.

## Соответствие материалам занятий

| Часть проекта | Использованные приёмы | Материал |
| --- | --- | --- |
| HTML-страницы | Заголовки, абзацы, списки, ссылки, изображения, подключение файлов | Л1 |
| Общий CSS | Классы, селекторы, размеры, отступы, цвет, шрифт, рамки, `:hover` | Л2–Л3 |
| Позиционирование | `position: relative/absolute/fixed`, `top`, `left`, `z-index` | Л4 |
| Разметка и навигация | Блочная вёрстка, Flexbox, выравнивание и перенос элементов | Л6–Л8 |
| Мобильная версия | Правила `@media` | Л7–Л8 |
| Карточки и колонки | `display: grid`, `grid-template-columns`, `fr`, отступы | Л9–Л10 |
| Фильтр и карусель | Переменные, функции, условия, циклы `for`, индексы и длина набора элементов | Л13 |
| Управление элементами | `getElementById`, `querySelectorAll`, `innerHTML`, `style`, `classList` | Л13–Л14 |
| Игра | CSS `@keyframes`, `animation`, `keydown`, `setTimeout`, `setInterval`, `getComputedStyle`, `parseInt` | Л15 |

Реализация использует обычные HTML, CSS и JavaScript. В файлах есть комментарии с номерами соответствующих лекций. Шрифт Verdana — системный, как в примерах курса.

## Игра

`js/game.js`: «Динозаврик и кактус». Кактус движется по CSS-анимации. Прыжок запускается добавлением класса `jump`; после прыжка класс удаляется таймером. Другой таймер проверяет координаты и столкновение. Есть счёт, текст результата и кнопка перезапуска.

Управление: «Начать игру», затем кнопка «Прыгнуть» или любая буквенная клавиша. На телефоне работают экранные кнопки. Готовой игры у автора не было, поэтому для проекта создана игра по примеру Л15.

## Редактирование

Страницы и тексты редактируются прямо в HTML. Карточки главной ведут к обычным разделам страниц. Изображения и подписи слайдов находятся в `index.html`, а переключение слайдов — в `js/carousel.js`. Меню и фильтр — в `js/blog.js`. После изменения файлов отправьте изменения в ветку `main`.

## Локальный запуск

Откройте папку в VS Code и используйте Live Server либо запустите статический HTTP-сервер. Для просмотра без сервера можно открыть `index.html` двойным щелчком.

Шрифт загружается из системы. Собственная аналитика, формы сбора данных и cookies в коде отсутствуют.
