# По ту сторону экрана — блог Данилы

Статический личный блог на HTML, CSS и JavaScript. Без сборки и серверной части.

## Страницы

- `index.html` — главная, знакомство, четыре карточки записей, фильтры и карусель из четырёх иллюстраций.
- `interests.html` — четыре увлечения и встроенная игра «Найди пару».
- `recommendations.html` — шесть аниме, фильмов и сериалов и восемь книжных рекомендаций.
- `places.html` — «Моя мастерская»: тематическая замена страницы мест, разрешённая заданием.
- `favorite.html` — любимый фиолетовый цвет и палитра блога.
- `404.html` — страница ошибки; не входит в пять основных страниц.

На всех основных страницах одинаковое меню, общий `css/style.css` и мобильная версия. Все локальные ресурсы подключены относительными путями. Изображения — оригинальные SVG-иллюстрации; персональные фотографии и официальные постеры не использованы.

## Игра

`js/game.js`: шесть пар компьютерных компонентов на двенадцати карточках. Есть инструкция, счётчик ходов, таймер, результат и перезапуск. Игра работает мышью, касанием и с клавиатуры.

В задании упоминается ранее разработанная игра. Готовой игры у автора не было; по его просьбе для проекта создана новая.

## Редактирование

Страницы редактируются напрямую в HTML. Тексты записей, которые открываются с главной, находятся в начале `js/blog.js`. Слайды — в `js/carousel.js`. После изменения файлов отправьте изменения в ветку `main`.

## GitHub Pages

Репозиторий: https://github.com/damila-alt-glitch/danila-blog

Планируемый адрес сайта: https://damila-alt-glitch.github.io/danila-blog/

Публикация: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Файл `index.html` расположен в корне, `.nojekyll` отключает обработку Jekyll. Установка зависимостей и команда сборки не нужны.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Локальный запуск

Откройте папку в VS Code и используйте Live Server либо запустите статический HTTP-сервер. Для просмотра без сервера можно открыть `index.html` двойным щелчком.

Шрифт Manrope загружается через Google Fonts; без интернета используется системный шрифт. Аналитики, формы сбора данных и cookies в коде нет.
